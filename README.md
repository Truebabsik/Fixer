# Fixer

Прототип нуарного тактического менеджмента. Ты — фиксер, прикованный к креслу: ты не управляешь боем, ты **отдаёшь приказы** и смотришь, как их исполняют. Три-четыре приказа за миссию, окна решений на каждом шагу, и молчание — тоже ход.

Движок: **Godot 4.7.2** (GDScript), 2D. Текущий этап: **ядро операции реализовано** (П1) — симуляция работает headless, без единого пикселя графики.

## Быстрый старт

```powershell
# Прогон проверок ядра: вердикт — код возврата процесса, 0 = зелено
tools\Godot_v4.7.2\Godot_v4.7.2-stable_win64_console.exe --headless --path game --script res://tests/run.gd

# Быстрый разбор без запуска
tools\Godot_v4.7.2\Godot_v4.7.2-stable_win64_console.exe --headless --path game --check-only --script res://tests/run.gd

# Редактор с проектом
tools\Godot_v4.7.2\Godot_v4.7.2-stable_win64.exe --path game --editor
```

Бинарники движка в репозиторий не входят (`.gitignore`). Версия зафиксирована в `docs/architecture.md` §1.

## О чём игра, в одном абзаце

Тезис: **компетентность против авторства**. Самый безопасный ход — молчать: именные доведут группу разумно. Но тогда на экране написано не «ты». Игра наказывает за молчание не смертью, а тем, что тебя в этой истории не было. Отсюда три ресурса: конечный пул приказов, шум команды (не затухает — это бюджет) и **эфир** (затухает — это след). Каждый приказ — передача, которую слышно: слишком часто говорить — потерять голос.

## Правила для работы в этом репозитории

`AGENTS.md` в корне: дизайн — в `docs/design.md`, решения — в `docs/desions.md`, разработка — в `docs/architecture.md`, текущие задачи — в `docs/current/`, завершённые — в `docs/archive/`, справочники — в `docs/spr/`, уровни — в `levels/` с обязательной индексацией в дизайне.
