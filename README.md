# Fixer

Прототип нуарного тактического менеджмента. Ты — фиксер, прикованный к креслу: ты не управляешь боем, ты **отдаёшь приказы** и смотришь, как их исполняют. Три-четыре приказа за миссию, окна решений на каждом шагу, и молчание — тоже ход.

Движок: **Godot 4.7.2** (GDScript), 2D. Текущий этап: **ядро операции реализовано** (П1) — симуляция работает headless, без единого пикселя графики. Контент миссии 01 заказан внешней сессии: постановка — `docs/handoff/2026-09-26-mission-content/`.

## О чём игра, в одном абзаце

Тезис: **компетентность против авторства**. Самый безопасный ход — молчать: именные доведут группу разумно. Но тогда на экране написано не «ты». Игра наказывает за молчание не смертью, а тем, что тебя в этой истории не было. Отсюда три ресурса: конечный пул приказов, шум команды (не затухает — это бюджет) и **эфир** (затухает — это след). Каждый приказ — передача, которую слышно: слишком часто говорить — потерять голос.

## Правила для работы в этом репозитории

`AGENTS.md` в корне: дизайн — в `docs/design.md`, решения — в `docs/desions.md`, разработка — в `docs/architecture.md`, текущие задачи — в `docs/current/`, завершённые — в `docs/archive/`, справочники — в `docs/spr/`, уровни — в `levels/` с обязательной индексацией в дизайне. Работа с субагентами, границы контекста и доказательство пробами — там же; рабочие шаблоны — в `docs/agents/`.

## С чего продолжать в новой сессии

1. **Проверить состояние:** `preflight` → `run.gd` → `run_red.gd` (команды в `docs/agents/constraints.md` §2;
   ожидание — 31/0, **906 проверок `failed: 0`**, код 0). Проверять **кодом возврата**, не текстом в stderr.
2. **Прочитать контекст этапа:** `docs/archive/2026-09-27-content-pipeline/summary.md` (итог и уроки) и
   `ledger.md` (решения с ценой ошибки). Дизайн конвейера — `design.md` той же папки.
3. **Ждать артефакты генератора** (`mission-01.json`, `texts.ru.json`), затем: положить их в `game/content/`,
   прогнать валидатором, собрать миссию, сделать первые замеры `docs/spr/scales.md` §10 — теснота бюджета,
   доля вмешательства (цель 30–40 %), порог тревоги.
4. **Дальше — презентация** (П2): экран операции по макету `docs/current/ui-operation-screen.svg`,
   карта, поток событий, эфир, строка «КОМАНДУЕТ», окно решения.

**Долги с условием возврата** (не забыты, записаны с причиной отсрочки — подробности в леджере этапа):

| Долг | Условие возврата |
|---|---|
| Обязательные текстовые группы (`log.*`, `voice.*`, …) не проверяются на наличие | когда появится `texts.ru.json` |
| `load_plan` без канала проблем: дубли `id` и «все записи битые» отбрасываются молча | когда появится фаза планирования |
| Условная обязательность полей разведки по `kind` | когда придёт контент с разными видами |
| Неохраняемая индексация в `test_windows.gd`, `test_harness.gd`, `test_content_loader.gd` (даёт `LOAD FAIL` вместо имени правила) | при ближайшей правке этих файлов |
| Поток `SCRIPT ERROR` в `sim/` на мусорном входе, недостижимом через валидатор | когда появится сборка миссии кодом (фаза планирования) |
