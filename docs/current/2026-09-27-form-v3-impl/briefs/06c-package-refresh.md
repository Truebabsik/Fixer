## Зачем

Пакет `docs/handoff/2026-09-27-mission-v3/` собран **до** правок по ревью, и в его комплекте лежат
**додефектные копии** боевого валидатора: слабое правило призрака (краснело только при полном
совпадении маршрута и периода, а решение требует, чтобы отличались **оба**) и диагноз «якорь
недостижим», ложно отвергавший законное окно охраны в отрезанном крыле. Свой `selfcheck` пакета этого
не видит — он сверяет пакет **сам с собой**. Получатель получил бы форму, которая пропускает три
дефекта призрака и бракует законный уровень.

## Что сделать

1. **Переложить исправленные боевые модули в комплект** (те же шесть: `game/content/validator.gd`,
   `problems.gd`, `loader.gd`, `game/sim/mission.gd`, `plan.gd`, `response.gd`) и обновить
   `kit/verifier/SHA256SUMS`. Доказать равенство **по SHA**, таблицей: боевой файл ↔ копия.
2. **Проверить, что документы формы соответствуют коду после правок**: `01-format.md` обязан
   описывать исправленное правило призрака (**маршрут И период обязаны отличаться; совпадение любого
   из двух — диагноз**) и уточнённый диагноз «якорь недостижим» (**только для окон, чей актёр —
   группа**; для окон охраны работает правило «сенсор без патруля»). Если в тексте есть расхождение с
   кодом — правишь текст пакета.
3. **Заново снять обязательные прогоны** (на изолированной копии, абсолютные пути):
   наш валидатор на образце (0 проблем, код 0); `selfcheck.gd` (0 нарушений, код 0); наш инструмент
   приёмки на образце (числа и код — **и** новая строка отказов); плюс **две пробы на исправленные
   правила**, обе на копиях образца: (а) призрак с тем же маршрутом и другим периодом → **названный**
   диагноз; (б) законный уровень с сенсорным окном в отрезанном крыле → **ноль проблем** (до правки
   он браковался). Выводы — дословно в отчёт.
4. **Поправить README пакета под факт**: числа прогонов, состав, и место, где сказано про вердикт
   инструмента на образце (норматив на нашем рабочем уровне по-прежнему не выполняется — оговорка
   остаётся, но числа обязаны быть текущими, а не из первой сборки).
5. **Пересобрать `.zip`** и сверить распаковку побайтово (как в первой сборке).
6. **Не трогать** `game/**`, прошлые пакеты (`…-mission-01-v2/`, `…-mission-01-delivery/`,
   `…-mission-content/`) и документы репозитория вне отчёта. Редактор Godot не запускать.
