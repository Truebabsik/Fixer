## 3. M2: возврат ветки — конверт, а не `int`

**Пробы (копия; канонический контент).** Ветка «критерии выполнены, но инструмент неисправен»
**недостижима ни на одном нашем контенте** (канонический уровень не проходит два критерия), поэтому
в копии сняты два имени из `CRITERIA` — скаффолд пробы, названный здесь прямо; логика судейства не
правилась. Инструмент на этом прогоне неисправен «сам по себе» — инвариант I6 (см. §2).

```
M2-A: скаффолд + СТАРАЯ строка (`return EXIT_CRITERIA`)          код 1
  ИТОГ ПРИЁМКИ: критерии выполнены, но инструмент неисправен — вердикт не выносится (код 1)
  АБОРТ  вердикт не выставлен: _accept() прервался, а не дошёл до вердикта (код 1)   ← ЛОЖЬ
M2-B: тот же скаффолд + ПРАВКА (`return _verdict(EXIT_CRITERIA)`)  код 1
  ИНСТРУМЕНТ: РАЗУМНЫЕ_ПРИКАЗЫ: … приказов 0 на объявленных маршрутах (на обеих выборках 27)
  ИТОГ ПРИЁМКИ: критерии выполнены, но инструмент неисправен — вердикт не выносится (код 1)
  (строки «АБОРТ … _accept() прервался» в выводе НЕТ)
M2-C: настоящий аборт ВНУТРИ `_accept()` (в копии `wrapper = null; problems = wrapper.size()`)  код 1
  SCRIPT ERROR: Invalid call. Nonexistent function 'size' in base 'Nil'.
  АБОРТ  вердикт не выставлен: _accept() прервался, а не дошёл до вердикта (код 1)   ← верно
```

Читается так: до правки **два разных состояния** (дошёл до вердикта / прервался) давали один и тот
же текст, и настоящий аборт терялся среди ложных; после правки аборт называется абортом, а ветка —
своим «вердикт не выносится». Код возврата в обоих случаях 1 (как и требовал бриф: аборт — 1,
нормальный путь — свой код).
