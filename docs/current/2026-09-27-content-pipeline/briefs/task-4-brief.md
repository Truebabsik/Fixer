## Обязательные ограничения проекта

1. Никаких `class_name` в `game/sim/`, `game/content/`, `game/tests/` — только `const X := preload("res://...")`.
2. Имя константы `preload` не совпадает с именем класса движка (`Window` запрещено — уже `WindowScript`).
3. `sim/` и `content/` не знают о нодах: только `RefCounted`.
4. Отступы — **табы**; идентификаторы английские, комментарии и имена тестов русские.
5. Детерминизм: никаких решений, зависящих от порядка словаря.
6. Типизация: объекты из `preload`-константы — через `:=`; из функций без аннотации возврата — через `=`;
   невыводимый тип — явной аннотацией (`: Variant`).
