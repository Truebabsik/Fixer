Этап: `content/` (конвейер данных) + `sim/` (окна читаются из данных). Основание —

## Состав папки

| Файл | Что это |
|---|---|
| `plan.md` | план этапа: шесть задач, приёмка, порядок и зависимости |

| `summary.md` | итог этапа: что сделано, уроки, оставленные долги с условием возврата |

## Про пути внутри `briefs/` и `reports/`

Артефакты писались, когда они лежали в рабочем каталоге `.superpowers/sdd/2026-09-27-plan-content-pipeline/`,
и **ссылки внутри них указывают на те пути**. Мы их не переписывали: это исторические документы, и правка
путей задним числом исказила бы то, что реально выдавалось исполнителям.

Соответствие простое:

```
.superpowers/sdd/2026-09-27-plan-content-pipeline/task-N-brief.md   →  briefs/task-N-brief.md
.superpowers/sdd/2026-09-27-plan-content-pipeline/*-report.md       →  reports/*-report.md
.superpowers/sdd/2026-09-27-plan-content-pipeline/progress.md       →  ledger.md
docs/current/2026-09-27-plan-content-pipeline.md                    →  plan.md
docs/current/2026-09-27-design-content-pipeline.md                  →  design.md
```

Копии в `.superpowers/` удалены: единственный источник правды — эта папка, она версионируется. Правило
на будущее — `AGENTS.md`, раздел «Структура документа».
