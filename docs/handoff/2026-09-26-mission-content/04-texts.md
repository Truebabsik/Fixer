# 04. Тексты

Текст — самая дорогая часть проекта и основное содержание игры. Здесь нет «атмосферных описаний»: реплика либо сообщает факт, либо молчит.

---

## 1. Формат файла `texts.ru.json`

Плоский словарь. Ключ → строка. Никакой вложенности.

```json
{
  "mission.01.title": "ХОЛОДНЫЙ АРХИВ",
  "window.w_bio_door.text": "Серверная. Биометрия. Внутри — инженер.",
  "window.w_bio_door.breach": "Выбить.",
  "window.w_bio_door.silence": "Кира обходит через второй этаж. Плюс шесть шагов.",
  "voice.kira.ack": "Принято."
}
```

Правила оформления:

- **Одна строка — одна реплика или один факт.** Если хочется двух предложений — пиши два ключа или два предложения в одном (это допустимо, если они — один факт).
- **Длина:** до 120 знаков. Окно читается на бегу, длинный текст убивает темп.
- **Без разметки.** Никаких `**`, `[]`, `<b>`, смайлов, markdown. Регистр — обычный; ЗАГЛАВНЫЕ допустимы только для служебных подписей интерфейса (`mission.01.title`, `hud.command.*`).
- **Кавычки:** «ёлочки», тире — длинное (—).
- **Голоса** обозначаются ключом, а не пометкой в тексте: `voice.kira.*`, `voice.echo.*`. Реплики БЕЗ голоса (журнал, факт от автора) — в ключах `log.*`.
- **Числа в текстах не дублируют механику.** Не пиши «+8 шума»: игрок читает последствия, а не таблицу. Допустимо и нужно: «плюс шесть шагов», «индикатор виден из холла», «они будут здесь через десять шагов» — то есть время и наблюдаемые факты, но не внутренние шкалы.
- **«Ты снова молчишь.»** — обязательная строка молчания, дословно. Она оформляет молчание как ход (см. `06-borders.md` §3).

## 2. Стайлгайд: законы и запреты

**Законы**

1. **Никаких монологов. Только паузы.** Многоточие, тире, обрыв — работают; развёрнутое рассуждение — нет.
2. **Никакая реплика не объясняет чувство. Только факт.** Плохо: «Кира боится за группу». Хорошо: «Кира: — Ещё раз так — и я не пойду.»
3. **Юмор — только у Эхо, и только когда страшно.** Он маскирует страх шутками. Кира не шутит никогда.
4. **Кира — минимум слов, максимум значения.** Её «Принято.» — высшая похвала. Её молчание дольше обычного — хуже крика.
5. **Никаких «это не твоя вина». Никогда.** Игра не утешает игрока.
6. **Никаких «мы спасём мир».** Мир не спасается: максимум — «доживём до следующего месяца».

**Запрещено**

| Запрет | Почему |
|---|---|
| Прилагательные-оценки: «жуткий», «зловещий», «леденящий» | Атмосфера делается фактами, а не эпитетами |
| Объяснение игроку его состояния: «тебе страшно», «ты чувствуешь вину» | Игрок сам решает, что чувствует |
| Мораль и выводы в конце реплики | Уровень не учит, а показывает |
| Восклицательные знаки в репликах группы | Эти люди не кричат |
| Имена врагов, лица, биография охраны | Мы их не видим — это премиса |
| Прямые подсказки механики: «потрать приказ», «это добавит шума» | Игрок должен понимать сам |
| Метафоры про море/звёзды/судьбу | Тон — технический, усталый, конкретный |
| Рифма, афоризмы, «красивости» | Это не тот жанр |

**Разрешено и работает**

- Обрыв на середине (`voice.echo.file_read` — он замолкает).
- Сухая констатация: «Дверь не открывается.»
- Время как факт: «Они будут здесь через десять шагов.»
- Профессиональный жаргон без объяснения: «Биометрия. Приманка не сработает.»
- Пауза как ответ: пустая строка в ключе допустима, если смысл — тишина.

## 3. Обязательные тексты по блокам

### 3.1 Переговоры (§14 уровня)

Два-три хода. В каждом игрок давит или уступает. Плюс досье и посредник.

| Ключ | Что там |
|---|---|
| `mission.01.title` | название уровня для интерфейса |
| `negotiation.intro` | первые слова посредника: задача, счёт, ничего лишнего |
| `negotiation.term.money` | ось денег: надавить / уступить |
| `negotiation.term.time` | ось сроков |
| `negotiation.term.truth` | ось правды: «сколько он готов заплатить за твоё незнание» |
| `negotiation.mediator.recognize` | «Ты тот самый? Который потерял команду?» |
| `negotiation.mediator.answer.press` | ответ фиксера, если давит |
| `negotiation.mediator.answer.yield` | ответ фиксера, если уступает |
| `negotiation.dossier.offer` | предложение купить досье на заказчика |
| `negotiation.dossier.read` | что видно в досье: связь с «Меридианом» без имени и без объяснения |
| `negotiation.deal` | контракт подписан. Условия известны. Или не совсем |

### 3.2 Команда (§15)

| Ключ | Что там |
|---|---|
| `team.kira.available` | Кира доступна: одна строка, без тепла |
| `team.echo.available` | Эхо доступен: одна шутка, потому что страшно |
| `team.market.intro` | биржа: цена, специализация — и то, чего не видно (Понимание) |

### 3.3 Окна

**По каждому окну из банка §13 уровня — обязательный набор:**

| Шаблон ключа | Что там |
|---|---|
| `window.<id>.text` | описание ситуации: что случилось. Одно-два предложения, факты |
| `window.<id>.<option_id>` | формулировка приказа от первого лица, как команда в эфир («Выбить.» / «Ждать, пока пройдёт.») |
| `window.<id>.silence` | что делает Кира при молчании: факт с ценой (время, шум, обход) |

Заготовки цен и последствий молчания уже сформулированы в тексте банка §13 — сохрани смысл, перепиши форму под стайлгайд.

**Обязательные (★) окна — пять:** `w_bio_door` (№2), `w_archivist` (№15), `w_echo_reads` (№20), `w_stuck_lift` (№27), `w_witness` (№30). Их id задай сам, но сохрани смысл.

**Сюжетные окна, которых нет в банке, но без которых уровень не читается:**

| Ключ | Что там |
|---|---|
| `window.w_lead_found.text` / `.silence` | зацепка: выгрузка в холодное хранение. Молчание — Кира не копает, и группа идёт дальше с догадкой вместо факта |
| `window.w_vault_cache.text` / `.silence` | на серверной только кэш; оригиналы выгружены |
| `window.w_cold_archive.text` / варианты / `.silence` | вход в холодный зал; три цены архивариуса |
| `window.w_archivist.<option>` (три варианта) | уговорить / обойти / убрать |
| `window.w_floor5.text` / варианты / `.silence` | опциональная ветка «за ответом» на 5-й: терминалы руководства |

### 3.4 Терминал (§12)

| Ключ | Что там |
|---|---|
| `ap.<id>.text` | терминал: что он предлагает |
| `ap.<id>.<action>` | по строке на действие: данные / деньги / зацепки / инструменты / уйти |
| `ap.<id>.trace` | след: сухая строка о том, что тебя теперь знают (всплывёт в «Итогах») |

### 3.5 Голоса: Кира и Эхо

Минимум — по 6 реплик на каждого, включая обязательные:

| Ключ | Условие | Что там |
|---|---|---|
| `voice.kira.ack` | приказ понят исполнение | «Принято.» |
| `voice.kira.doubt` | приказ спорный | сомнение без спора |
| `voice.kira.injured` | Кира ранена | «Я сказала. Нормально.» — не жалуется |
| `voice.kira.command` | игрок молчит, командует она | короткий приказ группе |
| `voice.echo.joke` | страшно | шутка, маскирующая страх |
| `voice.echo.order_ok` | приказ Эхо | шутит и исполняет мгновенно |
| `voice.echo.order_bad` | приказ был неверным | исполняет, потом молчит дольше обычного |
| `voice.echo.injured` | Эхо ранен | шутит ещё больше |
| `voice.echo.file_read` | ★ окно №20 | читает вслух — **и обрывается на середине** |
| `voice.echo.improvise.good` | импровизация Эхо, удачно | нашёл обход / услышал охрану заранее |
| `voice.echo.improvise.neutral` | нейтрально | сделал как собирался, но не как ты хотел |
| `voice.echo.improvise.bad` | плохо | создал новое окно |

**Про импровизацию:** удача не может убить (`06-borders.md` §2). Даже «плохо» — это проблема, а не смерть.

## 5. Проверка текстов перед сдачей

1. **Читал вслух?** Если фраза спотыкается — переписывай. Это единственная проверка тона, которая работает.
2. **Каждая реплика — факт или действие?** Если она сообщает чувство — переписывай.
3. **Нет ли двух строк подряд, которые говорят одно и то же?**
4. **Есть ли в тексте число механики** («+8 шума», «−2 эфира»)? Убирай: числа живут в интерфейсе, не в репликах.
5. **Кира молчит там, где могла бы объяснить?** Хорошо. Эхо шутит там, где не страшно? Плохо.
6. **Ключи совпадают с данными?** Каждый `*_key` из `mission-01.json` есть в `texts.ru.json`, и наоборот. Висячий ключ — ошибка.
