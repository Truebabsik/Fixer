# 07. Отчёт о самопроверке — шаблон

Заполни этот файл и сдай как `report.md` вместе с артефактами. **Отчёт — часть результата, а не приложение.** Без него артефакт не принимается: по нему мы понимаем, где ты сомневался и что решал сам.

Заполняй по факту. Пустой раздел пиши как «нет» — это нормальный ответ. Раздел, заполненный отпиской «всё в порядке», хуже пустого.
